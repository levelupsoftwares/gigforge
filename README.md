# GigForge

> A production-grade freelance marketplace REST API built with FastAPI, PostgreSQL, and SQLAlchemy.

GigForge is a backend-focused freelance marketplace where **clients post jobs**, **freelancers submit bids**, and **accepting a bid creates a contract**. Once the contract is completed, both parties can leave reviews and ratings.

The project is designed as a serious backend engineering project, with emphasis on:

- Clean layered architecture
- Authentication and authorization
- Database integrity
- Transaction-safe business workflows
- REST API design
- Automated testing
- API documentation
- Dockerized deployment
- CI/CD readiness
